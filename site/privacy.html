Политика конфиденциальности

Мы собираем минимальные данные для корректной работы ботов TPU Project и улучшения взаимодействия с пользователями.

  • ID пользователей и серверов
  • Сообщения команд
  • Базовую статистику использования

Данные не передаются третьим лицам и используются исключительно в целях безопасности и развития проекта.

Privacy Policy

We collect only the minimum data required for proper operation of TPU Project bots.

  • User and server IDs
  • Command messages
  • Basic usage statistics

No data is shared with third parties. All information is used solely to improve functionality and security.
