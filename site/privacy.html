Политика конфиденциальности

Мы собираем минимальные данные для работы ботов TPU Project. Это позволяет обеспечивать корректную работу функций и персонализацию взаимодействия.

  • ID пользователей и серверов
  • Сообщения команд
  • Основные статистические данные об использовании бота

Данные не передаются третьим лицам. Мы используем их исключительно для улучшения работы проекта и безопасности пользователей.

Privacy Policy

We collect minimal data required for TPU Project bots to ensure proper functionality and personalized interaction.

  • User and server IDs
  • Command messages
  • Basic usage statistics

No data is shared with third parties. We use it solely to improve project performance and ensure user safety.
